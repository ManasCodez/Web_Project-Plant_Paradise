# 🌿 Plant Paradise

> **Discover the beauty and benefits of plants around you.** 🌱

Plant Paradise is a beginner-friendly, visually focused plant information website created using **HTML and CSS**. The project presents different types of plants in a clean, nature-inspired interface with a photo-based hero section, category navigation, and plant information cards.

---

## ✨ About the Project

**Plant Paradise** is designed as a simple plant discovery website where users can explore plants based on different categories.

The website includes:

- 🌿 A stylish **hero section** with a collage-style plant image layout
- 🧭 A fixed **navigation bar** for easy page navigation
- 🌱 **Plant Categories** section
- 💚 Individual sections for different plant types
- 🪴 Plant cards containing images, descriptions, highlights, and uses
- 📩 A simple **Contact** section
- 📱 Basic **responsive design** for smaller screens

The project focuses mainly on **HTML structure and CSS styling**, making it suitable for a beginner-level web programming project.

## 🌼 Plant Categories

Plant Paradise currently includes six categories:

| Category | What it covers |
|---|---|
| 🌿 **Medicinal Plants** | Plants commonly associated with health, healing, and skincare |
| 🥬 **Edible Plants** | Plants and vegetables that are commonly eaten |
| 🪴 **Indoor Plants** | Plants that grow well inside homes |
| 🌸 **Flowering Plants** | Plants known for their beautiful flowers |
| 🥭 **Fruit Plants** | Plants and trees that produce fruits |
| 🌵 **Desert Plants / Succulents** | Plants adapted to dry environments and low-water conditions |

## 🎨 Design & UI

The design uses a **green and white nature-inspired color palette** to match the theme of the website.

### Main design elements

- 🌿 Green-themed color scheme
- 🖼️ Large image collage in the hero section
- 🔲 CSS Grid-based layouts
- 🧩 Card-based plant information
- ✨ Hover effects on navigation and category cards
- 📌 Fixed rounded navigation bar
- 📱 Responsive layouts using CSS media queries
- 🔤 **Playfair Display** for headings and **Poppins** for general text

---

## 🛠️ Technologies Used

This project is intentionally kept simple and uses:

- **HTML5** — Website structure and content
- **CSS3** — Layout, styling, colors, typography, hover effects, and responsiveness
- **Google Fonts** — Playfair Display and Poppins
- **Unsplash / external image URLs** — Plant photography used throughout the interface

No JavaScript or backend is required for the current version.

## 🚀 How to Run

1. Download or clone the project.
2. Keep `index.html` and `style.css` in the same folder.
3. Open `index.html` in any modern web browser.
4. Explore the different plant categories using the navigation links.

> 💡 An internet connection may be required because the project loads Google Fonts and several plant images from external URLs.

---

## 📱 Responsive Design

The website includes CSS media queries for smaller screens.

- **Desktop:** Multi-column category and plant-card layouts
- **Tablet:** Reduced number of columns
- **Mobile:** Single-column plant and category layouts

This allows the website to remain usable across different screen sizes.
